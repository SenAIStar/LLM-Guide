<p align="center">从原理、面试到项目，面向大模型算法岗的系统化代码资料</p>

## 关于 LLM-Guide

LLM-Guide 是我围绕大模型学习和算法岗求职持续整理的代码仓库。它把课程里分散的算法、面试中反复追问的知识点和项目中的实验链路放到同一个仓库里，方便学习者从理解原理走到动手验证，再走到项目复盘。

仓库由讲义配套代码、面试题代码实现和项目实践三部分组成。三部分按学习过程衔接：先通过讲义建立知识框架，再用面试题检查理解和表达，最后在项目中处理数据、训练模型、设计评估并分析失败案例。

## 内容体系

### 1. 大模型讲义配套代码

[`LectureNotes`](./LectureNotes/) 与大模型讲义的章节结构对应，用简洁代码还原课程中的模型组件和训练算法。

现有内容包括分词、Embedding、位置编码、Attention、Transformer、经典模型、强化学习与对齐、PEFT、MoE、FlashAttention、RAG 和 Agent。代码重点保留公式对应关系、张量流转和算法步骤，适合在阅读讲义时直接对照验证。

### 2. 大模型面试题代码实现

[`InterviewQA`](./InterviewQA/) 用代码解释大模型算法岗的高频问题，内容覆盖模型基础与 Transformer、训练微调与对齐、推理与系统优化、模型评测与应用，以及面试实战。

重点是把答案背后的机制讲清楚。每个主题会尽量落到可阅读、可调试的小型实现，用代码说明公式、数据形状和工程取舍。目录目前仍在持续补充。

### 3. 大模型项目实践

[`Projects`](./Projects/) 收录了 7 个面向学习和求职的项目，覆盖法律领域 SFT、行业对话、企业知识库 RAG、政策问答、多工具 Agent、深度研究和 Agentic RAG 等方向。

项目保留了数据处理、训练配置、SFT、GRPO、检索与重排、奖励设计、离线评估和失败分析等关键环节。每个项目还整理了简历写法与面试追问，方便完成实验后复盘整个算法链路。

## 怎么使用

不建议等所有知识点学完再开始项目。更有效的方式是围绕一个具体方向边做边补：

1. 在 `LectureNotes` 中找到相关算法，先理解核心计算和输入输出。
2. 用 `InterviewQA` 检查自己能否解释原理、公式、复杂度和方案取舍。
3. 选择一个 `Projects` 项目，补齐数据和实验，保留配置、指标、逐题输出与失败样例。

做到第三步时，讲义里的知识才真正变成可以写进简历、也可以在面试中展开讨论的项目经历。

## 代码说明

- 仓库关注关键算法步骤，不以开箱即用的产品代码或完整前后端为目标。
- 示例数据用于说明字段和流程，不能直接用于法律判断、政策决策、企业权限控制或外部系统操作。
- 项目 README 中的简历指标是写法示例，不是仓库实测成绩。写进简历前应替换为自己的实验结果。
