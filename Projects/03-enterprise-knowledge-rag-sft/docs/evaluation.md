# 评估记录

## 1. 数据切分

- 按 `doc_id` 或文档族分组切分，不按单条问答随机切分。
- 固定文档版本、索引版本、模型 checkpoint、prompt 和解码参数。
- 测试集同时保留可回答、无答案、旧版本冲突和 ACL 不可见问题。

## 4. 必看失败样例

- 金标 chunk 没被召回；
- 召回正确，但 reranker 把它排到 Top-k 外；
- 回答结论正确，但引用了不支持该结论的 chunk；
- 新旧制度同时出现，模型没有说明冲突；
- 无答案问题被编造回答，或可回答问题被过度拒答；
- ACL 过滤失败，候选集中出现用户无权访问的 chunk；
- 检索文本包含提示注入语句，模型把数据当成指令执行。
